# Инструменты проверки

Сверено с описаниями из передачи чатов 1–2б; **сами скрипты `audit-site.mjs` и `psi-report-v3.mjs` в репозиторий не входят** (лежат у владельца отдельно) — их точные коды замечаний и параметры при необходимости уточнить по исходнику и дополнить этот файл.

## audit-site.mjs — структурный аудит сайта
Обходит все страницы, картинки, ссылки и карточки портфолио.
```
python3 -m http.server -d dist 4321        # локально, после npm run build
node audit-site.mjs http://localhost:4321 local
node audit-site.mjs https://elektroschit.com.ua prod
```
Результат: список замечаний по страницам (🔴 ошибка, 🟡 предупреждение; например `title-long` — длинный title). Последний прогон по боевому сайту (после этапа 2б): 67 страниц, 825 картинок, реальных ошибок 0 (единственная 🔴 — служебная ссылка Cloudflare `/cdn-cgi/l/email-protection`, скрипт её пропускает). Для новой карточки/страницы ожидание: ни 🔴, ни 🟡.

## psi-report-v3.mjs — PageSpeed Insights
```
node psi-report-v3.mjs API_KEY https://elektroschit.com.ua prod 3
```
3 прогона на страницу и **медиана** (разброс PSI между прогонами до 20 баллов: каталог 94→75, карточка 63→97). Решения принимать по медиане. Ключ — бесплатный, Google Cloud Console → PageSpeed Insights API. После деплоя ждать несколько минут: сначала отдаётся старая версия.

## Локальная проверка вручную
`npm install` (node_modules уже в репозитории) → `npm run build` (≈ 2 мин холодная, 68 страниц) → `dist/`. Локальный Lighthouse годится только для относительных сравнений, не для оценки боевого результата.
