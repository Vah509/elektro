## Как выбирать значения
- `types`: основной раздел продукции первым; дополнительные — если щит относится сразу к нескольким (например димовидалення + двигуни). `shafi-keruvannia` — общий тип для шаф управления, не попавших в узкий раздел.
- `tags`: только если реально подходит (`avr` — есть АВР; `sylova-shafa` — силовой щит).
- `properties`: технические особенности, видимые в характеристиках (способ пуска, контроль фаз, схема АВР).
- Значения вводятся ключами (латиница, дефисы) в двойных кавычках: `types: ["hrshch"]`.
